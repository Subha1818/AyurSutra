# AyurSutra — Panchakarma Health & Therapy Management Platform

> Built for the Smart India Hackathon (SIH), AyurSutra is a comprehensive digital healthcare platform designed to streamline, standardize, and scale Ayurvedic Panchakarma treatment workflows.

## ⚡ Quick Start

### 1. Install Dependencies
```bash
npm install
# or
pnpm install
```

### 2. Run Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

---

## 🛠️ Tech Stack Highlights
- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS, Shadcn/UI (Radix UI)
- **Visuals & Charts**: Recharts, Framer Motion, Lucide React
- **Backend & Auth**: Supabase (`@supabase/supabase-js`)
- **AI Integrations**: Google Gemini API (Symptom analysis, smart scheduling, clinical notes summarizer, 24/7 wellness chatbot)
